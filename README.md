# datasource-anim-female-face

A blendshape face model and its baked exports, staged for turning facial blendshape animation into skinned bone animation.

## What it is for

The face model carries a full set of facial expression blendshapes. It is exported once as a bind-pose mesh with its armature and once as baked per-frame animation, the two inputs a skinning-decomposition tool needs. The notes beside the face sketch that pipeline.

## Build and run

Clone it with its submodules and open the project in the Godot editor.
